# 設計ドキュメントのテンプレート

新しい機能、モジュール、公開データ型、またはクラス相当の構造を実装する際は、次のテンプレートを基に`docs/designs/<機能名またはモジュール名>.md`を作成または更新します。ファイル名は小文字kebab-caseを使用します。

小規模な変更では「概要」「責務と依存関係」「公開インターフェース」「検証方法」を記載し、それ以外の項目は必要に応じて省略できます。
