# ハードウェア仕様

## 概要

- 状態: 確定（電気仕様）
- 対応Issue: #15
- 対象: USB MIDI Pedalの電源、入出力回路、主要部品およびGPIO使用方針

本書は、製品要件を満たすために確定した電気仕様を記録する。GPIO番号の詳細は[ピン割り当て](pin_assignment.md)、I2C ADCの選定経緯は[ADC選定](designs/adc-selection.md)を参照する。

## 電源

- 電源入力はTiny 2040基板上のUSB-C端子のVBUS（5 V）のみとする。
- 外部9 Vペダル電源および電池には対応しない。
- USB Power Deliveryなどの電源交渉は行わない。
- Tiny 2040の3.3 Vレギュレータ出力を、GPIO、I2Cバス、SH1106 OLED、ADS1015およびEXPペダルの励起電圧に使用する。
- USBの5 Vは74HCT14とDIN MIDI OUTの電流ループにのみ使用する。

```mermaid
flowchart LR
    usb[USB-C / VBUS 5 V] --> tiny[Tiny 2040]
    usb --> hct[74HCT14]
    tiny --> v33[3.3 V]
    v33 --> oled[SH1106 OLED]
    v33 --> adc[ADS1015]
    v33 --> exp[EXPペダル]
    hct --> din[DIN MIDI OUT]
```

## 表示・入力・出力

| 機能 | 確定仕様 |
| --- | --- |
| OLED | 1.3インチ、128×64、SH1106、I2C、3.3 V |
| フットスイッチ | 2端子、ノーマリーオープン（NO）、モーメンタリーを6個。MCP23017 I2C GPIOエキスパンダーで入力する。スイッチ内蔵LEDは使用しない。 |
| ロータリーエンコーダー | 機械式インクリメンタル方式、A相・B相・押しボタンを使用する。 |
| EXP入力 | 6.35 mm TRSジャックを1個使用する。Tipはワイパー、Ringは3.3 V、SleeveはGNDとする。 |
| USB MIDI | Tiny 2040のUSB-C端子を使用する。USB MIDI OUTを提供する。 |
| DIN MIDI | 5ピンDINのMIDI OUT専用とする。MIDI IN、THRU、USBからDINへのスルーは提供しない。 |
| デバッグUART | 3.3 V TTLのUART TX専用出力を設ける。USB MIDIおよびDIN MIDIとは独立した診断用インターフェースとする。 |

### フットスイッチとエンコーダーの入力回路

- フットスイッチとエンコーダーの各接点は、入力をGNDへ落とすactive-low入力とする。
- 各フットスイッチはMCP23017のGPA0〜GPA5へ接続する。MCP23017は3.3 Vで動作させ、I2Cで読み取る。
- 各フットスイッチ入力は、3.3 Vへの10 kΩ外部プルアップ、1 kΩ直列抵抗およびGNDへの100 nFコンデンサを備える。MCP23017の内蔵プルアップは使用しない。
- エンコーダーA相、B相および押しボタンは3.3 Vプルアップ入力とし、ソフトウェアでデバウンスする。
- フットスイッチもソフトウェアでデバウンスする。誤検出防止を操作遅延より優先する。

### EXP入力とADC

- ADS1015を使用する。12 bit、4チャネル、PGA付きのI2C ADCである。具体的なパッケージ型番は実装方式と調達先を決めるときに確定する。
- ADC、EXPペダルおよびI2C信号は3.3 V系で動作させる。
- EXPワイパーをADS1015の単一エンド入力AIN0へ接続する。PGAは0〜3.3 Vの入力範囲を扱える設定にする。
- EXPワイパーとADC入力の間には、保護用の直列抵抗とノイズ低減用コンデンサを配置する。値は実機でADC変換精度と応答性を確認して決定する。
- ADS1015は連続変換モード、1.6 kSPSで動作させる。EXP値は`ALERT/RDY`のData Ready割り込みごとに取得するため、1 ms以下のサンプリング周期を満たす。
- Data Readyモードは、上限しきい値を`0x8000`、下限しきい値を`0x0000`、コンパレータキューを有効値に設定して有効化する。極性はactive-lowとする。

### I2Cバス

- SH1106 OLED、ADS1015およびMCP23017は同じI2Cバスを共有する。
- バス速度は400 kHz（Fast-mode）、信号レベルは3.3 Vとする。
- ADS1015の7 bit I2Cアドレスは`0x48`とする。SH1106 OLEDのアドレスは`0x3C`または`0x3D`に設定し、重複を避ける。
- MCP23017の7 bit I2Cアドレスは`0x20`とする。アドレス端子A0〜A2はGNDへ接続する。
- SDA/SCLのプルアップは3.3 Vへ1組だけ配置する。モジュール側のプルアップを有効化する場合、基板側には重複して配置しない。
- ADS1015の`ALERT/RDY`は3.3 Vへのプルアップ抵抗を設け、GP0へ接続する。変換完了パルスの立下りエッジで割り込みを発生させる。

### DIN MIDI OUT

- Tiny 2040のUART TXを、5 Vで動作する74HCT14の2段へ接続し、5 V・非反転のUART信号に変換する。
- 74HCT14の出力と5 Vを、それぞれ220 Ω抵抗を介してDIN端子の5番・4番へ接続する。
- DIN端子の2番ピンはGNDへ接続しない。
- この回路は電圧レベル変換であり、ガルバニック絶縁ではない。MIDI OUT専用のため送信側にフォトカプラは設けない。

### デバッグUART TX

- UART0 TXのGP28をデバッグUART送信専用に使用する。
- 出力信号は3.3 V TTLレベルとし、外部USB-UART変換器のRXへ接続する。5 V UART機器へは直接接続しない。
- 筐体内にはGNDとTXを出す2ピンのデバッグ端子を設ける。端子の具体的な型番は未決定とする。
- デバッグUARTはTX専用とし、RXおよびフロー制御は設けない。
- DIN MIDIのUART1 TX（GP4）とは別のUARTペリフェラルを使用する。

## GPIO使用方針

MCP23017でフットスイッチ入力を扱うことで、Tiny 2040のGPIO使用数を8本に抑える。割り当ては[ピン割り当て](pin_assignment.md)を参照する。GP1、GP6、GP7およびGP26は将来の物理入力または出力に使える。
