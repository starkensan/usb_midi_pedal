# プロジェクト固有スキル

このディレクトリでは、USB MIDI Pedalの開発で繰り返し使用するエージェント向け手順を管理します。

スキルは次の場所へ追加してください。

```text
.agents/skills/<skill-name>/SKILL.md
```

## 追加方針

- ひとつのスキルには、ひとつの明確な目的を持たせます。
- ディレクトリ名は小文字のkebab-caseを使用します。
- `SKILL.md`の先頭に、スキル名と適用条件を記述します。
- 手順はこのリポジトリからの相対パスを使用し、再現可能にします。
- 補助スクリプトはスキルの`scripts/`、参考資料は`references/`、テンプレートは`assets/`へ配置します。
- 一般的な開発規約は重複して記載せず、ルートの`AGENTS.md`を参照します。

具体的な作業手順が固まった時点でスキルを追加します。
